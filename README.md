# 女仆咖啡厅 · 冰淇淋与拉花工坊

一个单文件的 WebGL 小游戏（three.js r128），在咖啡杯里放冰淇淋球、拉花、画画、摆小装饰。

直接用浏览器打开 `maid-cafe.html` 即可，需要能访问 cdnjs 加载 three.js。电脑和手机都能玩。
